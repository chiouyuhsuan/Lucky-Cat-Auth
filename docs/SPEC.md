# LuckyCat 重構規格（2026-10-21 確認）

## 1. 範圍
- 網站維持公開，任何人都能註冊、上傳、上排行榜。
- 核心流程：上傳貓照 → 貓選號 → 開獎後自動對獎 → 累積中獎率與獎金 → 產出分享圖卡。
- Email 通知：本次不做，資料欄位預留。

## 2. 樂透
- 台灣大樂透：貓只選 **6 個號碼**（01–49），不選特別號。對獎依 `docs/LOTTERY_RULES.md`。
- US Powerball（5+1）、日本 Loto6（只選 6 碼）：保留選號，介面標示「僅娛樂，不自動對獎」，不計入中獎率與排行榜。

## 3. 期別歸屬
- 選號當下決定期別並存入資料，畫面與圖卡顯示「第 XXX 期・MM/DD（週X）開獎」。
- 開獎日 20:00 前選號 → 算當期；20:00 後 → 算下一期。

## 4. 統計
- 所有台灣大樂透選號都對獎，計入「貓的中獎率」與「貓的累積獎金」。
- 「我買了」：使用者手動標記，只能在該期開獎日 20:00 前標記或取消，之後鎖定。
- 標記為已買的選號另外統計「實際花費（每注 $50）、實際獎金、損益」，只在本人紀錄頁顯示。

## 5. 分享圖卡
- 只做選號圖卡：貓照、貓名、6 顆號碼、期別、開獎日、樂透類型。
- 兩種尺寸：1:1（1080×1080）、9:16（1080×1920），各自排版。
- 選號完成可產出；紀錄頁每一筆都能重新下載，內容與當初相同。
- 手機用系統分享選單，電腦下載 PNG。

## 6. 照片
- 每組選號保留當時上傳的照片。
- 存兩個版本：圖卡用大圖（長邊約 1080px，JPEG）、列表用縮圖。
- 存放於 Firestore 獨立集合，列表只讀縮圖；存取包成獨立模組，日後可改用 Firebase Storage。

## 7. 舊資料
- 寫成手動執行的 GitHub Actions 工作：先備份 → 去掉舊的第 7 顆號碼 → 補期別 → 用歷史開獎結果重新對獎 → 輸出異動清單。
- 舊紀錄的「我買了」一律為未知，不計入實際損益。

## 8. 排行榜
- 以貓為單位，三個分頁：獎金榜、中獎率榜（至少 10 次台灣大樂透選號）、最新選號。
- 不顯示任何人的購買與損益資料。

## 9. 必修項目（不需另外決定）
- 移除外洩的 Gemini API key（使用者需自行在 Google Cloud 撤銷）。
- Firestore 安全規則：使用者只能建立／修改自己的資料；中獎欄位只有後端可寫。
- 修正所有 `innerHTML` 插入使用者內容造成的 XSS。
- 合併重複的對獎排程與腳本，只保留「抓開獎結果」→「對獎」兩段。
- 統計數字改用計數欄位，不再整個集合讀出來算數量。
- 個人紀錄改用自己的資料查詢，不受全站筆數限制。
- 壓縮 6.2MB 的 loading GIF。
- Firebase 設定與共用函式抽成共用模組。
- 多國語系補齊（中／英／日）。
