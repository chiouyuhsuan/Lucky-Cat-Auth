# 台灣大樂透 中獎規則（2026-10-21 查證）

## 玩法
- 玩家從 01–49 選 **6 個號碼**，每注 NT$50。
- **玩家不選特別號。**
- 開獎時先開出 6 個號碼，再從剩下的 43 個號碼中開出 1 個「特別號」，所以特別號一定不會和 6 個主號碼重複。
- 判斷是否「中特別號」：看**玩家的 6 個號碼裡，是否包含開出的特別號**。
- 開獎時間：每週二、週五 20:30 左右（實際約 20:40 公布）。

## 獎項

| 等級 | 獎項 | 條件（玩家 6 碼與開獎號碼比對） | 獎金 |
|---|---|---|---|
| 1 | 頭獎 | 6 個主號碼全中 | 浮動（總獎金扣固定獎後 82%，可累積） |
| 2 | 貳獎 | 任 5 碼 + 特別號 | 浮動（6.5%） |
| 3 | 參獎 | 任 5 碼 | 浮動（7%） |
| 4 | 肆獎 | 任 4 碼 + 特別號 | 浮動（4.5%） |
| 5 | 伍獎 | 任 4 碼 | 固定 NT$2,000 |
| 6 | 陸獎 | 任 3 碼 + 特別號 | 固定 NT$1,000 |
| 7 | 柒獎 | 任 2 碼 + 特別號 | 固定 NT$400（2014/9/26 起新增） |
| 8 | 普獎 | 任 3 碼 | 固定 NT$400 |

浮動獎項同級多人中獎時均分，每期實際金額要以開獎後公布為準。

## 對獎程式邏輯
```
matched = 玩家6碼 ∩ 開獎6個主號碼 的數量
has_sp  = 開獎特別號 ∈ 玩家6碼
```
| matched | has_sp | 結果 |
|---|---|---|
| 6 | – | 頭獎 |
| 5 | 是 | 貳獎 |
| 5 | 否 | 參獎 |
| 4 | 是 | 肆獎 |
| 4 | 否 | 伍獎 |
| 3 | 是 | 陸獎 |
| 3 | 否 | 普獎 |
| 2 | 是 | 柒獎 |
| 其他 | | 未中獎 |
